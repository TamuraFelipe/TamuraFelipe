## ⚡ Minhas Habilidades & Tecnologias

### 🎨 Front-end Development
- **HTML5 & CSS3**: Construção de estruturas semânticas, acessíveis e layouts totalmente responsivos.
- **JavaScript (ES6+)**: Desenvolvimento de funcionalidades dinâmicas, interatividade moderna e manipulação eficiente de dados no client-side.
- **React & Next.js**: Criação de interfaces de usuário (UI) modernas, performáticas e escaláveis. Aplicação de conceitos como Renderização no Lado do Servidor (SSR), Geração de Sites Estáticos (SSG) e otimização de rotas/SEO.
- **jQuery**: Manipulação simplificada do DOM, tratamento de eventos e animações pontuais em projetos legados.
- **Estilização & Frameworks CSS**:
  - **Tailwind CSS & Bootstrap**: Desenvolvimento ágil de interfaces estilizadas e focadas em componentes responsivos.
  - **Sass (SCSS)**: Organização e modularização de estilos complexos com variáveis, mixins e aninhamento.

### 🔄 Integração & APIs
- **Consumo de APIs REST**: Integração fluida entre front-end e back-end utilizando Fetch API e Axios.
- **Swagger**: Leitura, testes e validação de documentações de APIs para garantir integrabilidade precisa dos dados.

### 🛠️ Ferramentas, Versionamento & Workflow
- **Git & GitHub / Bitbucket**: Controle de versão avançado, gerenciamento de branches, code review e colaboração contínua em equipe.
- **VS Code**: Meu ambiente de desenvolvimento principal, otimizado com extensões para alta produtividade e boas práticas de código.
